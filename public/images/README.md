# Fotos

Diese Dateinamen sind im Code bereits verdrahtet. Sobald eine Datei hier liegt, wird sie automatisch angezeigt –
bis dahin erscheint eine dunkle Fläche mit Sternenpunkt-Muster. Quelle: Instagram @salonmajesto (keine Stockfotos).

| Datei | Einsatz | Format |
|---|---|---|
| hero.jpg | Hero, vollflächig (Interior mit Sternenhimmel-Decke) | Querformat, ideal ≥ 2000 px breit |
| interior-1.jpg | Galerie (Barber bei der Arbeit) | 4:5 |
| cut-2.jpg | Galerie | 4:5 |
| cut-1.jpg | Galerie | 4:5 |
| team-yakup.jpg, team-yasin.jpg, team-enes.jpg, team-suad.jpg | Team (Graustufen, Hover farbig) | 4:5 |
| insta-1.jpg, insta-2.jpg, insta-3.jpg | Instagram-Bereich | 1:1 |

Nach dem Hinzufügen neu deployen (bzw. `npm run build`).
